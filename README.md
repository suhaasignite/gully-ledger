# 🏏 Gully Ledger

A mobile-first local cricket scoring and live viewing web application.

## 🌐 Live Website

[https://gully-ledger-tpasskaroo-4251.vercel.app](https://gully-ledger-tpasskaroo-4251.vercel.app)

## 📖 About the Project

Gully Ledger is designed for local gully cricket and tennis-ball cricket matches. It allows admins to record live ball-by-ball scores while viewers can follow match progress without logging in.

The application provides two main experiences:

- 🛠️ **Admin Scoring** — full match management and live ball-by-ball entry
- 👀 **Public Live Viewing** — real-time scores and scorecards, no sign-in required

Admins can create matches, configure teams and players, manage overs and toss details, record ball-by-ball scores, add extras, record wickets, and update match results.

Viewers can browse available matches, follow live scores, and view scorecards without signing in.
